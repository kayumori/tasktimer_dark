# タスクタイマー

Notion 埋め込み用の、経過時間を数え上げるだけのシンプルなタイマー。ページを開いた時点から `HH:MM:SS` で加算する。

## 公開 URL

https://kayumori.github.io/tasktimer_dark/

Notion のページで `/embed` → 上記 URL を貼り付けて使う。

## テーマ

右下の**スイッチ**でライト / ダークを切り替える。選んだテーマはそのブラウザに保存され、次に開いたときも維持される。

最初からライトで開きたい場合は末尾に `?theme=light` を付ける。
テーマの決定順は「スイッチで選んだ設定 → `?theme=` → ダーク」。一度スイッチを操作すると、以降はそちらが優先される。

## 仕様

- 枠外はライト `#fff` / ダーク `#202020`
- 枠は内壁のグラデーション（`--rim`）と縁の影（`--inset`）の 2 層で、窪んだ盤面に見せている。どちらのテーマでも影は黒
- 外部リソースなし。`index.html` 単体で動作する
- リロードすると 00:00:00 に戻る（経過時間は保存しない）

## 保存キー

| キー | 内容 |
| --- | --- |
| `tasktimer-theme` | `light` / `dark` |

## 色の変え方

配色は `index.html` 冒頭の `:root`（ダーク）と `html[data-theme="light"]`（ライト）に CSS 変数としてまとめてある。
